GoldHEN · Remote Package Installer · fPKG altyapisi uzerine kurulmustur

① Uzaktan kurulum (RPI)

  1. PS4'te Remote Package Installer uygulamasini acin ve ekranda birakin
  2. Ust bardaki ⚙ PS4 Baglantisi ile konsol IP'sini tanimlayin
  3. PS4'e Gonder butonuna basin, bildirimlerden kurulumu izleyin

② USB ile kurulum (GoldHEN)

  1. PKG Indir ile dosyayi bilgisayara kaydedin
  2. exFAT/FAT32 USB bellegin kok klasorune kopyalayin
  3. PS4'te GoldHEN'i aktif edin: Ayarlar → GoldHEN → Package Installer
⬇ PKG Indir (USB) 🌐 Kaynak Sayfa

PS4 Baglanti Ayarlari

Remote Package Installer uygulamasinin PS4'te acik ve odakta olmasi gerekir. IP'yi Ayarlar → Ag → Baglanti durumunu görüntüle ekranindan ogrenebilirsiniz.
